.. rubric:: Recent releases

**v1.3.3** (2026-05-11)
   Added ``sortino`` and ``directional_accuracy`` metrics, ``fynance.models.loss``
   submodule with differentiable PyTorch losses (``SharpeLoss``, ``SortinoLoss``,
   ``DirectionalAccuracyLoss``).

**v1.3.2** (2026-05-07)
   Python 3.13 CI support, Read the Docs configuration, Codecov and interrogate
   coverage badges, CI improvements, models split into one-file-per-class.

**v1.3.1** (2025-12-08)
   See `CHANGELOG.md <https://github.com/ArthurBernard/Fynance/blob/master/CHANGELOG.md>`_
   for details.
